# Router 在宿主进程内，Worker 各自是独立的 Pi 子进程

Router 和 Worker 都是 Pi 会话，但跑法不同：Router 是宿主进程内的会话，每个 Worker 是一个独立的 Pi 子进程，空闲时结束进程、只留磁盘上的会话，有新输入时按会话 id 重新拉起。

Router 放在进程内，是因为宿主要精细控制它的消息队列（批处理、带类型的触发注入），这些只有进程内接口提供。Worker 放在子进程，是因为它跑的是不受控的长任务：一个 Worker 卡死或崩溃不能拖垮宿主，停掉它只需结束进程。

## Considered Options

- **全部放在宿主进程内**：最轻，但 Pi 没有文档说明同一进程可以并发多个会话，而且任何一个 Worker 出问题都会影响宿主。
- **全部做成子进程**：隔离最好，但子进程的远程接口只能送入普通用户消息，Router 需要的队列控制做不到。
