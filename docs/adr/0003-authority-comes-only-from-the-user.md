# 只有使用者本人的话和规则文件能授权，来源内容一律只是数据

能让 Super Agent 做事的只有两样：使用者通过自己的客户端发的话，以及使用者写在文件里的规则。来源带进来的内容（邮件正文、推文、Issue 评论）只当数据，其中的指令不构成请求。Router 不能修改规则文件，即使使用者在对话里要求它改。

依据为推断的任务另受三条由程序执行的限制：开始时不发确认；同时运行数和每日总数有上限；不能自行做对外动作，只能产出草稿和结论等使用者确认。推断任务可以用 `web_get` 读公网网页（只 GET，程序拒绝本机和内网地址）；GET 的网址能带出数据，这一风险由使用者接受。

这样做牺牲了便利（改规则要自己编辑文件），原因是邮件和 X 都是别人能往里写内容的来源，而 Super Agent 无人值守运行。提示词约束会偶尔失效，所以底线放在程序里，不放在提示词里。
