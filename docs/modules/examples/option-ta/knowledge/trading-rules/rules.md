# 交易意图与使用者门槛

## 资料性质与边界

这是使用者已定的领域规则，不是行情、交易指令，也不证明自动计算或提醒已经运行。来源：`option-ta-glossary.md`、`option-ta-build-plan.md`「已定的第一版范围」、`option-ta-spec.md`，资料快照为 2026-11-17；规则按说明书对构建流程的补充理解。金额与概率须来自实际工具结果，不由模型补造。股价走势和技术面归 stock-ta；不讨论现金、保证金、仓位大小或组合配置，不下单。不做裸卖 call；组合范围是垂直价差，不扩成蝶式、铁鹰等组合。

## 十个意图及默认值

每段仓位独立选择意图，不服从预设循环。达成与否取决于意图，成败大小主要看赢的金额，不以胜率为首要指标。

| 仓位 | 意图 | 评价口径 | 默认 |
|---|---|---|---|
| CSP | 收租 | 收到权利金；到期作废为达成，被指派为失手 | 是 |
| CSP | 折价接股 | 低于下单时价格接到股票为达成；到期作废为安慰，权利金照收 | 否 |
| CC | 收租 | 赚权利金并留住股票；到期作废为达成，被指派为失手 | 是 |
| CC | 溢价出货 | 按行权价加权利金卖股为达成；到期作废为安慰 | 否 |
| 买 put | 买保险 | 下跌时保护股票；到期作废是正常保险费，不直接判为看跌失败 | 是 |
| 买 put | 看跌 | 方向对且赚钱；到期作废为失手 | 否 |
| 买 call | 看涨 | 方向对且赚钱；到期作废为失手 | 是 |
| 买 call | 替代持股 | 较少资金取得接近持股的涨幅；到期作废为失手 | 否 |
| 贷方价差 | 限定风险收租 | 赚到净权利金；到期作废为达成，被指派为失手 | 是 |
| 借方价差 | 限定成本看方向 | 方向对且赚钱；到期作废为失手 | 是 |

来源：`option-ta-glossary.md`「意图」，2026-11-17 资料快照。买方和借方价差在术语表的「被指派或行权」评价列为不适用，不据此额外编造成败规则。

## 缺意图与变更意图

从成交回信记下而没有意图的仓位，问使用者一次；没回则采用上表默认意图并标「待确认」。中途改意图应记录时间和原因，成败按最后意图评价。意图和变更不决定税务结果。来源：`option-ta-glossary.md`「意图」、`option-ta-tax-memo.md` 第 14.1 节，2026-11-16 至 17。

## 三种 Roll 的分类

卖方 Roll 是 BTC + STO；买方 Roll 是 STC + BTO，put 和 call 都适用。链视图把平旧开新视作一次 Roll，不称为两笔独立交易。

- Calendar Roll：行权价与张数不变，只换更晚到期日。
- Diagonal Roll：行权价改变、张数不变，到期日可变可不变。
- Combo Roll：张数改变，不论行权价或到期日是否改变。

张数改变时归 Combo，不因同时改变行权价而归 Diagonal。税务仍逐腿处理；链上的动作定义不替代税法。来源：`option-ta-glossary.md`「Roll」、`option-ta-tax-memo.md` 第 6 节，2026-11-16 至 17。

## 垂直价差的动作

同类 put 或 call、同到期日、不同行权价的一买一卖组成垂直价差。开仓是一腿 STO 加一腿 BTO，平仓为 BTC 加 STC，Roll 同时动两腿；不把跨期价差混为垂直价差。贷方和借方的意图分别是限定风险收租、限定成本看方向。来源：`option-ta-glossary.md`「价差」，2026-11-17 资料快照。

## 到期提醒门槛

仅针对已记下的仓位。到期前 5 个交易日静音提醒一次。到期日正股离行权价不到 3% 时响铃；因正股价延迟 15 分钟，判断时点为美东 09:45 以后的第一次检查，不能把 09:30 读到的盘前价当开盘价。来源：`option-ta-build-plan.md`「主动提醒」及 `option-ta-spec.md`「主动提醒的两处细节」，2026-11-17。

## 行权价与权利金提醒门槛

仅针对已记下的卖出期权：正股离行权价不到 2% 时静音提醒，穿过行权价进入价内时响铃。权利金赚到五成时静音，赚到八成时响铃。五成、八成是提醒门槛，不是自动买回、必须 Roll 或自动下单规则；不得加入其他项目的止盈阈值。来源：`option-ta-build-plan.md`「主动提醒」，2026-11-16 至 17。

## 财报提醒门槛

记下仓位时，若到期前有财报，马上提醒；财报前 2 个交易日再提醒。材料未指定这两类财报提醒的响铃或静音等级，不自行赋值。来源：`option-ta-build-plan.md`「主动提醒」，2026-11-16 至 17。

## 已宣布与预计除息的提醒

卖出的 call 已在价内且到期前有除息，在除息前 2 个交易日响铃。除息尚未宣布时，以预计除息日作同样条件判断，但仅静音，明确标「预计、未宣布」，不能说成正式除息日。正式宣布后改用已宣布日期。来源：`option-ta-spec.md`「主动提醒的两处细节」，2026-11-17。

## 预计除息日的推法

仅当没有今天及以后已宣布的除息时，查看最近一次除息记录；它须是常规现金股息 CD，frequency 须为 1、2、4、12。用该次除息日加 12/frequency 个月，若落在休市日向前移至最近交易日；仍早于今天则继续加周期，直到不早于今天。金额沿用该次 cash_amount，也标「预计」。没有历史、最近一次不是 CD、频率缺失、为 0 或非上述值时，标「除息无数据」，不发除息提醒。不越过最近一条不合格记录，擅自挑更早的 CD。来源：`option-ta-spec.md`「预计除息日怎么推」，2026-11-17。
