# 税务第14节：保守降级与双视图

## 来源、适用范围与核验状态

主要依据使用者自写 option-ta-tax-memo.md 第14.1–14.3节，必要背景来自第1–6、10–12、15–16节。memo 记录核验时间为 2026-11-16，使用 IRS Pub 550 (2025)、1099-B Instructions (2026)、8949 Instructions (2025) 及法条/条例；本轮只整理该材料，未访问这些网页，不能说成本轮独立核验。这里只适用于美国联邦个人投资者一般规则，不涵盖州税、做市商、§475 trader、IRA 内部损益和外币。不是税务/法律/投资建议，申报须与券商报表及税务专业人士核对。P2 税务工具、自动标记、快照采集均显式未实现，以下是目标与边界。

## memo 14.1：一套不可变原始事实

账户保留匿名 account_key、tax_owner_key、tax_type；不能默认所有账户同一纳税人或默认 taxable。合约保留类别、OCC、方向、行权价、到期、乘数、交割物、结算方式、美/欧式和待报表核对的 tax_class。不能把调整合约乘数一律写成 100。

Fill 按账户记录方向、数量、每股价格、成交日/时刻、交割日、费用明细和来源；指派/行权股票 BUY/SELL 的 caused_by_event 指回事件。Event 记录 EXPIRE、ASSIGNED、EXERCISED、CASH_SETTLED、券商报日期、数量、费用。原始记录不可改，更正追加冲销，不把税务推算当事实塞回原账。

## 成交日、费用和缺信息

税年、持有期、wash sale 窗口以成交/事件日期处理，交割日只作现金对账。指派买股日期按券商确认单，不自行推算；memo 把这项实务处理标为推论。佣金和各类费用分别保留；未知不等于 0，缺费用最多列明示未扣费毛额，不冒充可对账净额。账户归属或税务类型未知，跨账户结果只能列缺项。

## memo 14.2：双视图不可互换

交易链按账户、链成员、Roll 组和意图看累计权利金、净收、有效成本与成败。税务视图逐腿看实现损益、税年、性质及风险标记，不读 Roll 组；删除 Roll 分组不应改变税务结果。两者使用同一组成交/事件，不互写原始记录。派生结果可缓存但必须可删重算，不手改派生账。链的有效成本永远不能写成股票批次的税务成本。

memo 的一致性检查适用于同税年全部结束且无待确认递延等例外的完整链：链总盈亏与税务各行之和核对。跨年、wash sale、跨式递延及 §1256 年末计价会改变时点或性质，不能硬要求每个单独税年无条件相等。市场另卖股票不在记录范围时，不能宣称整链已经完整结束。

## Roll 在税务上仍逐腿实现

链里一次 Roll 是一个动作；税务上旧腿 BTC/STC 平仓实现损益，新腿 STO/BTO 有独立权利金或成本。卖方平仓和到期一般短期；买方一般看期权自身持有期，但 QCC、§1233、§1256 等例外不能忽略。旧腿已实现盈亏不滚入最后指派股票成本；只有最后被指派/行权那腿按相应规则并入股票。

依据：memo 第2–6节；[Pub 550, Writers](https://www.irs.gov/publications/p550#en_US_2025_publink100010630)、[Holders](https://www.irs.gov/publications/p550#en_US_2025_publink100010628)、[Table 4-3](https://www.irs.gov/publications/p550#id879)、[§1234](https://www.law.cornell.edu/uscode/text/26/1234)。链接随 memo 保留，未在本轮重新核验。

## memo 14.3：第一版 B，哪些数据明确不记

2026-11-16 使用者选 B：只记期权成交/事件，以及指派和买方行权交割的股票，不记普通股票买卖。第一版不做独立股票批次管理、LotSelection 批次指定、StraddleIdentification 跨式标识、开 CC 时用于 QCC 的行情快照、BrokerReport/1099-B 导入或对账。看不到股票批次不是「已经查过且不存在」，相应判断必须降级。

## memo 14.3：QCC 待确认（包括 ETF）

每张 CC（含 ETF）标「QCC 待确认」。价内 QCC 的股票持有期暂停及损失改长期也待确认，不能据普通卖方短期规则给确定性质。以后需股票批次、取得日，以及开 CC 时前一日收盘、当天开盘和该到期日全部可用行权价快照。依据 memo 第14.3、8.1–8.5节；[Pub 550, QCC](https://www.irs.gov/publications/p550#en_US_2025_publink100010648)、[§1092](https://www.law.cornell.edu/uscode/text/26/1092)、[§1.1092(c)-1](https://www.law.cornell.edu/cfr/text/26/1.1092(c)-1)。

## 股票关联跨式、§1233 与 wash sale 待确认

股票+put、股票+CC 的跨式、持有期/损失性质/年末特别规则、买 put 视为卖空及 married put、涉及股票的 wash sale 一律待确认。需全部股票成交、股票批次取得日、必要的指定/标识和年末快照；跨账户按税务归属人看，不能只看一个账户或只看 option-ta 的期权记录。memo 未证实保护性 put 下 §1233 与 §1092 的逐项优先顺序，不能自己裁定。

依据：memo 第14.3、5、7–9、15节；[§1233](https://www.law.cornell.edu/uscode/text/26/1233)、[§1091](https://www.law.cornell.edu/uscode/text/26/1091)、[Pub 550, Straddles](https://www.irs.gov/publications/p550#id883)、[Wash Sales](https://www.irs.gov/publications/p550#id854)。

## put 被指派与 call 买方行权得到股票

目标中的一般处理：put 指派买股成本为行权价对应买股金额减最后一腿净权利金，持有期从确认单买入日次日起数；call 买方行权成本为行权价对应金额加该 call 买入成本，持有期从行权日次日起数，不并入期权持有期。这不是把整条 Roll 链净收入减进成本。

仍有同标的买入 put 未结束（例如 put 价差卖腿指派而买腿还在），或前后 30 天可能有模块看不到的股票亏损卖出时，成本/持有期相关结果待确认；不能从期权记录断言外部股票交易不存在。依据 memo 第14.3节和第3、5–7、9节；[Pub 550, Option exercised](https://www.irs.gov/publications/p550#en_US_2025_publink100010556)。P2 不输出伪装成工具完成的数字。

## put 行权与 call 指派交出股票

put 买方行权的卖股所得可按行权金额减该 put 成本整理，但交出股票成本和长短期待确认，§1233 也可能影响持有期。call 指派所得按行权金额加最后一腿净权利金整理；股票若可追溯至已记指派/行权，成本沿前节并保留例外，否则成本待确认。

call 指派的长短期，仅在开该 CC 时这批股票已持有超过一年、批次和日期可追溯且符合 memo 条件时按相应规则整理；开 CC 时不足一年因 QCC 不明，长短期待确认。不能只按指派日距最初买股超过一年就断言长期。依据 memo 第14.3节、[§1.1092(b)-2T](https://www.law.cornell.edu/cfr/text/26/1.1092(b)-2T)。

## 超一年个股买入 put 的例外

持有超过一年的个股买入 put，第一版长短期一律待确认：§1233(b)(1) 在有相关短期持股等情形下可能让收益仍算短期，而第一版看不到这些股票批次。不能把所有超过一年 put 收益自动列长期。依据 memo 第14.3节最后部分、[Pub 550, Put option as short sale](https://www.irs.gov/publications/p550#en_US_2025_publink100010629)。

## memo 14.2、14.3：只做风险标记，不自动调账

第一版目标保留能从期权记录分析的每腿损益、税年和一般长短期、价差双腿跨式标记、期权之间 wash sale 风险标记。但「实质相同」、BTC 亏损是否属相关 sale、替换仓位为卖出期权如何处理、§1256 是否适用 wash sale 等在 memo 第15节未证实，标风险不等于税务裁决。

不自动禁扣 wash sale、不自动递延跨式亏损、不自动改成本。「待确认」是可重算派生标记，不写成原始交易事实。以后补数据再重算，不靠模型常识补法理。

## 保留 §1256 的 60/40 目标

memo 第10、14.3节要求：已确认的 §1256 合约按长期 60%、短期 40% 拆分，年末仍持有时按当年最后交易日公允价值计价，后来平仓调整已计部分。SPX 是 memo 的宽基指数 nonequity option 示例、现金结算，不交割股票；不能套指派股票成本算法。QQQ/SPY ETF 期权非 §1256 是 memo 按法条的推论，最终以券商分类核对；NDX 等其他指数是否宽基未逐一核对，不能一概推断。

依据：[§1256](https://www.law.cornell.edu/uscode/text/26/1256)、[Pub 550, Section 1256](https://www.irs.gov/publications/p550#id526)、[60/40](https://www.irs.gov/publications/p550#en_US_2025_publink100010338)。P2 尚未实现计算，不因股票批次降级而删掉这一产品目标。

## 保留期权年末快照，但采集尚未实现

memo 第14.3节明确保留每年最后交易日仍持有的 §1256 期权和价差腿收盘价，供年末计价及另一腿未实现收益参考。这些是期权行情事实，不是另一套账，不属于已明确不做的「开 CC 时 QCC 快照」。不能混淆后删掉年末目标，也不能以价格缺失填 0。

过程说明书建议 private market-snapshots 承载这些数据，因为选择哪些合约暴露持仓；该落点是工程建议，不是已验证采集能力。P2 未实现，不能声称已留存年末价格或完成跨式损失可扣计算。

## §1256 目标与指数行情过滤的冲突

P1/说明书的行情规则只留 O:<标的> 前缀且 american，以去掉 O:B1 二元期权；SPX 是 european，因此不能在保留此过滤的同时宣称已支持 SPX 链、指数实时分析或年末估值。税务目标继续保留，行情分类、过滤和采集须 P3 单独补强；不能擅自放开二元期权。
