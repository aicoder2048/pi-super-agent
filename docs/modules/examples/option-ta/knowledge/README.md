## 阅读顺序与不能混淆的点

术语以 glossary 原文为准，其「会回填」「自算」等描述是目标，不是已实现保证。交易链里 Roll 是一个动作，税务仍逐腿实现；链有效成本不是股票税务成本。QCC（含 ETF）、股票批次/持有期相关判断待确认；不要因为股票批次降级而删除 §1256/60:40 和期权年末快照目标。行情当前 american 过滤不覆盖 SPX european，不能宣称已支持指数行情。过程说明书假设不替代使用者已定门槛。
