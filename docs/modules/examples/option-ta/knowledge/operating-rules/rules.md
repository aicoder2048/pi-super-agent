# 第一版规则与提醒门槛

## 来源和适用范围

依据使用者的 `docs/modules/option-ta-build-plan.md`「已定的第一版范围」与 `docs/modules/option-ta-spec.md`，版本截至 2026-11-17，具体提交见旁边的 `source.json`。动作和意图以本包 glossary 原文为准。

第一版记期权开仓、Roll、平仓、到期、指派、行权，以及指派或买方行权产生的股票进出；普通股票买卖不记。只做垂直价差，不做裸卖 call。股价和技术面归 stock-ta；现金、保证金、仓位大小、组合配置不属本模块。输出是分析和提醒，不是下单指令。

## 提醒门槛

主动提醒只针对已经记下的仓位；以下是使用者已定门槛，不是自动交易条件。

| 条件 | 提醒 |
|---|---|
| 到期前 5 个交易日 | 静音一次 |
| 到期日开盘时，正股离行权价不到 3% | 响铃；在美东 09:45 以后的第一次检查判断，避免把延迟的盘前价格当开盘价格 |
| 卖出的期权，正股离行权价不到 2% | 静音 |
| 卖出的期权，正股穿过行权价进入价内 | 响铃 |
| 卖出的期权，赚到权利金五成 | 静音 |
| 卖出的期权，赚到权利金八成 | 响铃 |
| 记仓位时，到期前有财报 | 马上提醒；财报前 2 个交易日再提醒 |
| 卖出的 call 在价内，到期前有已宣布的除息 | 除息前 2 个交易日响铃 |
| 同上，但除息尚未宣布、使用预计日期 | 只静音，必须标「预计、未宣布」 |

提醒本身不等于买回、Roll 或接受指派的结论；仓位研判须结合意图。不能用其他研究的门槛替换这张表，也不能把提醒阈值改写成使用者已定的止盈交易规则。

## 预计除息日

接口只能给已宣布的除息。没有今天及以后已宣布的除息时，按最近一次常规现金股息（`CD`）的除息日及频率推算：频率只接受每年 1、2、4、12 次，加上 12/频率个月；落在休市日则前移到最近交易日，仍早于今天就继续加一个周期。金额沿用该次金额，也标「预计」。

没有记录、最近一次不是 `CD`、频率缺失或不在上述集合时，标「除息无数据」，不发除息提醒。每个交易日重查一次，发现正式宣布就换成宣布的日期。预计日期不能说成已宣布的除息日。

## 成交来源与意图

券商交易台的人工「成交回信」是非正式更新，不是正式成交确认单，数以邮件为准，含糊就问。挂单不是成交；部分成交按订单累计成交的增量记，不把单行当整单，补齐后旧行不改。按账户记，原始记录更正用新记录冲销。

仓位没有意图时问一次；未回复才用术语表的默认意图，并标「待确认」。意图改变要记时间和原因，成败按最后意图判；主要看赢的金额，胜率仅供参考。

## 已知假设不当事实

部分成交按「邮件数量是累计成交量」处理是说明书明示的待验证推测，不是已证实的邮件事实；遇到首封真实部分成交信需核实。邮件缺订单号、成交时间、佣金、费用时留空并标「待确认」，不能补造。

价格、IV、希腊值、日期、行权价、张数、金额及税务出处均不能编造。模型假设、来源数据和使用者已定规则应分开表述。
