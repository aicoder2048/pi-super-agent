## 用户已定门槛（材料2026-11-16/17）
- 到期前5个交易日静音一次；到期日美东09:45后首次检查，正股距行权价不到3%响铃，不在09:30用盘前延迟价判。
- 仅卖方：距行权价不到2%静音；穿过进入价内响铃。开仓权利金赚到五成静音，八成响铃；这不是强制买回指令。
- 记仓发现到期前有财报立即提醒，财报前2交易日再提醒；等级未定，默认静音（假设）。
- 卖出call价内且到期前有已宣布除息，除息前2交易日响铃；预计未宣布同样检查但只静音并写「预计、未宣布」。每交易日重查宣布日期。

## 预计除息规则
未来已宣布为空时，用最近一条记录；必须是CD常规现金股息且frequency为1/2/4/12，日期加12/frequency个月，休市向前移，仍早于今天再加周期；金额沿用并标预计。无记录、最近不是CD或frequency不支持就无数据、不提醒，不能跳过最新记录找更早CD假装有效。P2不取数据、不预测日期。
