# 持仓提醒规则
来源：使用者已定的第一版范围（build plan，2026-11-16/17）及spec补充（2026-11-17）。这里只针对记下的未结束仓位，不扫开仓机会。门槛是提醒，不是自动买回、Roll或下单指令；不能把theta参考规则变成硬闸。

## 门槛
- 到期前5个交易日静音一次。
- 到期日美东09:45以后的第一次检查，正股离行权价不足3%响铃；正股延迟15分钟，09:30仍可能是盘前数据，不当开盘。时刻不适用、缺行情不宣称风险排除。
- 仅卖出期权：离行权价不足2%静音；穿越行权价进入价内响铃（卖put是正股<行权价，卖call是正股>行权价）。严格“不到”，等于2%/3%不触发距离线。
- 仅卖出期权：权利金赚到50%静音、80%响铃。按同账户同合约未平仓部分开仓均价对可买回ask，不用Roll全链净收替当前腿开仓价；缺ask不触发。未知费用标未计费用。
- 记下仓位时，已公布财报在到期前，立即提醒；财报前2个交易日再提醒。区分盘前/盘后；缺事件数据不称无事件。
- 卖call价内且到期前有已宣布除息，除息前2个交易日响铃。未宣布的预计除息按相同条件、仅静音，必须写“预计、未宣布”。宣布后换成已宣布，允许升级提醒。

## 预计除息
watch自己用Massive，不能调外部工具。每天重查一次dividends；今天及以后已宣布记录非空时不推算。否则看最新记录：仅最新一条是CD常规现金股息，且frequency属于1/2/4/12才推算。最近除息日加12/frequency个月，休市则前移最近交易日，继续加周期直到不早于今天；cash_amount沿用并标预计。最新记录非CD、无记录、频率缺失/0/不支持，标除息无数据，不发除息提醒。不能跳过最新非CD去挑较旧CD制造预测。

## 日历、数据与去重
交易日必须本模块美股节假日/早收市日历，不按工作日简单相减。watch自行取现价、期权报价、除息（POLYGON_API_KEY）、财报（FINNHUB_API_KEY），不经外部网关。对齐正股与期权时刻，报价0/缺字段不等于无风险。
同仓位、类别、门槛只提醒一次；50/80、接近/穿越、预计/已宣布各自去重，更高线可升级；落回后再次穿越默认不反复。记录去重键和来源时刻，不能失败也推进成功cursor。
watch不写into，提醒全文按非私密发Telegram，使用者已接受持仓细节（2026-11-17）；只含必要合约/张数/权利金进度，不发邮件全文、真实账号、税务归属和密钥。

## 状态诚实
阈值是行为契约，不是已运行证明。只有feed实际交回有效检测结果才声称已检查。problem/NOT_IMPLEMENTED原样转述；不发空的“安全”结论、不谎称监控正常。没有有效采集与日历支持时，只列待补能力。
