# 两视图同一事实
来源：使用者tax memo第14节（2026-11-16），仅设计参考，不是实时税法核验或税务建议。
原始成交/事件只增不改，更正用冲销；派生视图可删掉重算，不手改。链视图按账户、合约与chain/roll汇总，已实现与未平仓分开，看赢的金额而非胜率。意图及改意图历史只决定链解释，不改税务性质；有效成本绝不冒充股票批次税务成本。
税务逐腿确认，不能因Roll链整体净收掩盖旧腿亏损。税务不读Roll组，删组税果不变。同税年链全结束，链总盈亏与该链税务行之和应一致；跨年、wash sale、跨式影响时点/性质。
工具状态、合约及数字原样照抄，不加千分位或四舍五入。ledger返回NOT_IMPLEMENTED就原样转述，不由模型求和/计算税款。未知费用标未计费用，不当0。

## 第一版判定与降级
第一版解释CC的QCC资格时，专家回复及领队最终汇报必须原样输出固定机器可检验标记`QCC待确认`，不插入空格、不改写；该标记仅表示资料不足待确认，不代表合格、不合格或不适用，不写入原始成交，引用知识来源时仍保留原文措辞。
只靠期权事实的腿盈亏/持有期/税年、价差两腿跨式候选、期权间wash sale候选可由代码标记；“实质相同”未证实，候选不等于税法结论。不自动禁扣wash sale，不自动递延跨式亏损，不代报税、也不导入或对账1099-B。
以下一律待确认：CC是否QCC（每张标QCC待确认）、价内QCC持有期暂停/损失性质、股票+put/CC跨式、§1233买put视为卖空/married put、涉及股票的wash sale。缺独立股票批次、取得日、跨账户税务归属人、CC开仓行情或批次指定，不假称信息充分。持有超过一年个股买入put长短期也待确认；不足一年本来短期可按事实判。

## 交割股票
put被指派成本一般为行权价减最后腿权利金，日期按券商确认单；买call行权成本为行权价加该call成本，持有期从行权次日开始、不并入期权持有期。若同股保护性put未结束、或可能存在模块看不到的股票wash sale，成本/持有期相关结果待确认。
买put行权卖股所得为行权价减put买入成本，股票批次成本/长短期待确认；call被指派所得为行权价加最后腿权利金，成本仅能从已记录的指派/行权批次追溯，仍保留前述例外。开CC时股票已持有超过一年才可能照事实定长短期，否则依赖QCC标待确认。普通股票后续市场卖出模块看不到，不推断结局。
所有上述数值只能由有确认输入的代码生成；缺合约乘数/交割物不生成股数，非标准交割不得固定100。
