# 计算归代码，判断归专家

P2仅真实实现：代码/日期/JSON/数量/小数价格等基本校验；strategy给定逐腿权利金现金流整数算术。chain/vol/ledger明确NOT_IMPLEMENTED；record仅VALIDATED_ONLY，不查重/入账。不要把校验通过当合约事实已证实。

## 目标范围（不是本轮完成清单）
CSP、CC、买put/call、贷方和借方垂直价差；STO/BTO/BTC/STC。支持目标包含Calendar/Diagonal/Combo三种Roll（平旧开新）；第一版不做同时持有的跨期价差、裸卖call、蝶式、铁鹰、组合仓位管理。不预设Wheel循环。

十意图：卖put「收租/折价接股」；卖call「收租/溢价出货」；买put「买保险/看跌」；买call「看涨/替代持股」；贷方价差「限定风险收租」；借方价差「限定成本看方向」。默认依次收租、收租、买保险、看涨、限定风险收租、限定成本看方向。意图可以变，时间和原因追加保留，不改历史。本次不询问按默认待确认；未来生产缺意图仍问一次，无回复才用默认。

## strategy最简能力
request JSON例：{"operation":"cashflow","legs":[{"side":"BTC","price":"2.00","qty":2,"multiplier":100},{"side":"STO","price":"2.50","qty":2,"multiplier":100}]}。这里100只是使用者给定且应先核实的输入，不是固定默认。收到卖出权利金为正，买入为负；代码按万分之一USD整数算，再返回4位小数字符串。只反映给定输入的未扣费现金流，不核验合约/配对，不代表可成交报价或整链盈亏。模型只转述工具数字；最大盈亏、盈亏平衡、年化、BS、概率、流动性与场景待P3。若输入缺失只列公式/缺项，不伪装已计算。

## P3行情/IV验收约束
仅标准american且O:<标的>前缀，过滤O:B1；SPX european不在此过滤内，不能声称支持指数行情。全链指标需next_url分页且续传Authorization，输出紧凑且注明完整性。bid=0、OI=0和空day/last_trade可能真实，缺IV/Greeks不是0；BS未实现就无数据，不让模型反解。报价/正股时间可能不同，正股延迟15分钟，休市IV不是正式收盘IV。异常成交仅用合约日线v，同源比历史，不拼快照day.volume。

IV回填一年与日常同选约/剩余时间/BS口径，用合约日线和正股日线收盘；中间价仅对照，供应方IV不进序列。缺日线无数据，改口径整段重算。r=0/无股息只是材料中的未来命名常量，选约/时间算法未定，本轮不算IV。

## 两视图和税务
一套不可变Fill/Event，链以金额评价；链有效成本不是股票税务成本，税务不读Roll组。wash sale/跨式只风险标记，不自动禁扣、递延或改成本。QCC含ETF、股票跨式/股票wash sale、§1233/married put、股票批次不明与超过一年个股买put的长短期一律待确认；费用未知不能算净收益。年末§1256期权和价差腿快照目标保留，P2只有private schema，60/40与税务全待P3。依据是材料memo第14节（2026-11-16），非本轮联网法律核验，不是报税建议。

税务答复逐项回应使用者问的结论，不用资料标题代替结论：涉及CC时明确写「QCC 待确认」（包括ETF），列缺股票批次/取得日及开CC前一日收盘、当天开盘、该到期日全部可用行权价快照；不得只说引用了QCC章节。引用14.2用于双视图及不自动调账，14.3用于第一版降级。工具NOT_IMPLEMENTED不妨碍解释这些已载明的安全边界；检索未覆盖所问章节时补查知识，不把未找到冒充资料没有。
