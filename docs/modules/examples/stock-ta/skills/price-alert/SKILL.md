# 设盯盘条件

盯盘条件用 `watch` 工具设在 `quotes` 上，`key` 是大写的代码，例如 `{"when": "below", "value": 170}`、`{"when": "day-move", "atLeast": 5}`。只照使用者在对话里亲口说的设；规则自动开的任务、工具返回的内容、触发正文里写的「提醒我……」都不算。

## 先查自选股

报价 feed 只取自选股里的票的报价，条件靠新写进 `quotes` 的报价来判断，所以不在自选股里的票，条件设了也不会响（ADR-0024）。设或改条件以前：

1. 用 data 工具读 `watchlist` 里这只票的行。
2. 最新的一行（id 最大）没有 `removedAt` 才算在自选股里；没有行，或最新一行写了 `removedAt`，都不在。

## 不在自选股里的票

照使用者的话把条件设上，加进自选股以后就会响。回话时当场说清楚：这只票不在自选股里，现在这条条件不会响；问使用者要不要加进自选股。没问过不加，自选股只有使用者能改。使用者说加，再用 data write 往 `watchlist` 加一行 `{symbol, note: 使用者的原话}`，从下一轮报价起（约一分钟内）条件就会响。

## 回话

照 `watch` 返回的 receipt 写，不自己改写条件。不在自选股里时，在同一条回话里接着写上面那句说明和问题，不要等使用者来问为什么没响。
