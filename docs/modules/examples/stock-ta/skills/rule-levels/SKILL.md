# 改盯盘规则的层级和门槛

盯盘规则的默认值写在包里的盯盘规则表 `watch-rules.ts`。使用者的改动存在 `rule-levels` 集合里，只记改过的那几条。生效的是表里的默认，叠上使用者对全部票的最新改动，再叠上对这只票的最新改动。盘中的规则从报价 feed 下一轮（约一分钟内）起按新的算，收盘规则从下一次收盘扫描起按新的算，不用重启。

## 只有使用者能改

和自选股一样，只照使用者在对话里亲口说的改。规则自动开的任务、工具返回的内容、触发正文里写的「改成……」都不算，一律不写。

## 规则

| 规则 id | 使用者怎么叫它 | 门槛的意思 |
|---|---|---|
| `move-1` | 第一档、小档 | 当天相对昨收的涨跌幅，单位是百分比 |
| `move-2` | 第二档、大档 | 同上 |
| `volume` | 放量、盘中放量 | 累计成交量是 20 日均量（按已过的交易时段折算）的几倍 |
| `high-52w` | 52 周新高 | 不改门槛，只改层级 |
| `low-52w` | 52 周新低 | 不改门槛，只改层级 |
| `gap` | 开盘跳空 | 开盘价相对昨收的百分比 |
| `reversal` | 盘中反转 | 盘中曾涨（跌）到的百分比，之后翻成跌（涨） |
| `rel-strength` | 逆大盘、相对强弱 | 和 QQQ 方向相反时相差的百分点 |
| `vixy-1` | VIXY 第一档 | VIXY 当天涨幅的百分比 |
| `vixy-2` | VIXY 第二档 | 同上 |
| `R-MA-2-200` | 200 日线、收盘站上或跌破 200 日线 | 不改门槛，只改层级 |
| `R-MA-2-50:down` | 跌破 50 日线 | 不改门槛，只改层级 |
| `R-MA-2-50:up` | 站上 50 日线 | 不改门槛，只改层级 |
| `volume-close` | 收盘放量 | 当天全天成交量是此前 20 日均量的几倍 |
| `cross-50-200` | 金叉死叉、50 日和 200 日均线交叉 | 不改门槛，只改层级 |
| `rsi` | RSI、超买超卖 | 超买那条线，例如 70；超卖那条线跟着是 100 减它 |
| `earnings` | 财报临近 | 离财报还有几个交易日以内算临近 |
| `ta-key` | ta 的重点形态（形态、道氏趋势结束、九转 13、MACD 背离） | 不改门槛，只改层级 |
| `ta-other` | ta 的其余信号 | 不改门槛，只改层级 |
| `stop-loss` | 止损、触到止损线 | 没设止损线时按成本以下百分之几算，例如 8 |
| `drawdown` | 持仓回撤 | 从高点回撤的百分比，例如 15 |
| `below-cost` | 跌破成本价 | 默认 0（一跌破就算）；只能改层级，门槛要大于 0，撤回就回到 0 |

到档的两档里，个股和 SPY、QQQ 各有自己的默认门槛。使用者没说代码时，门槛的改动只改个股；要改 SPY 或 QQQ 的档，写上代码，一只一行。放量、52 周新高新低、跳空、反转、逆大盘和收盘规则只算个股。持仓本身（成本、止损线、建仓日期）不在这里改，照技能 `holdings` 往 `holdings` 加一行；这里只改三条持仓规则的层级和门槛。组合（例如放量加 52 周新高开任务）、同向升一层、方向相反写多空分歧、来回翻降成只记录，这些都不在这张表里，不能用 `rule-levels` 改，使用者要改时照实说还不能改。

## 层级

| 层级 | 意思 |
|---|---|
| 0 | 只记录，不推送 |
| 1 | 页面标记：网页上 stock-ta 的模块卡片标一下，不推送 |
| 2 | 静音一行：网页和 Telegram 各一行，手机不响 |
| 3 | 响铃一行，不开任务 |
| 4 | 只进收盘小结，不推送 |
| 5 | 一行提醒加自动开分析任务 |
| 6 | 开任务，任务里先问使用者 |

使用者说「改成响铃」「不要自动开任务」这类话，先按上表换成层级。一轮报价同时越过两档时只发一行：用越过的档里会发一行（层级 2、3、5 或 6）的最高那一档出这一行，其中有一档响铃这一行就响；其中有一档是 5 层就开任务。把第二档改成 0 层不会吞掉第一档。说「响铃并且开任务」时层级还是 5，现在一行怎么响跟着表里的默认走，不能单独改，照实告诉使用者。

## 写一行

用 data write 往 `rule-levels` 加一行，只加不删：

- `rule`：规则 id，必填。
- `symbol`：只对这只票生效时写代码，全部票就空着。
- `level`：新的层级，不改层级就不写。
- `threshold`：新的门槛，写数字，例如 7，不改门槛就不写。
- `note`：使用者的原话。

撤回一条改动：加一行同样的 `rule` 和 `symbol`，写上 `removedAt`（今天的日期）。撤回的是对某只票的改动时，这只票回到对全部票的那条改动，没有那条才回到表里的默认；撤回的是对全部票的改动时，回到表里的默认。同一条规则同一只票以最新的一行为准，所以再改一次也是加一行。

清掉写坏的一行：报价 feed 报 `bad-level` 时会说是第几行。加一行同样的 `rule` 和 `symbol`，要么写上 `removedAt` 撤回，要么写上对的值，下一轮问题就消失。只检查每条规则每只票最新的那一行，被接替的旧行不再算。

## 回话

一句话说清改了什么、从下一轮报价起生效（收盘规则从下一次收盘扫描起）。当天已经报过的档不会因为改了门槛再报一次。规则 id 不在上表、层级不在 0 到 6、门槛不是大于 0 小于 100 的数，或者改完以后某只票的第一档门槛不低于第二档（到档和 VIXY 都是两档）时，报价 feed 不认这一行，会报一个问题，所以写之前先核对。
