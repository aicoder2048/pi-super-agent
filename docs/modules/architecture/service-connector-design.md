# 模块之间的服务连接器（设计稿 C4）

状态：草稿第 1 版，2026-11-16。使用者同意做法 B 和先后（C4 排在模块工坊做 option-ta 之前），细节待对抗复查和确认。

## 为什么要做

stock-ta 是 option-ta 的底层。option-ta 的「方向与价位」专家要正股的趋势、支撑阻力、信号，stock-ta 已经有，背后是土拨鼠引擎和专家知识。option-ta 再做一套简化版，既重复又更差。

可模块是扁平且隔离的（ADR-0018）：任务只用得到本模块的能力。使用者否决了两条路：
- 经幕僚长中转：幕僚长要保持轻量；中转靠模型转述，数字会转错；会诊被拖长。
- option-ta 自己做简化版：重复。

选定的做法：一个模块可以把自己的几个**只读工具**开放出来，别的模块按名字调用，宿主替它在提供方那边运行。这和 `mail` 连接器是同一个思路：mail 连接器共享一种外部服务，服务连接器共享一个模块的只读能力。

## 规则

1. **提供方声明开放哪些。** `module.json` 加 `exports`，列出开放的工具：

   ```json
   { "name": "stock-ta", "exports": ["tools/structure", "tools/signals", "tools/prices", "tools/quote"] }
   ```

   只能开放 `effect` 是 `pure` 或 `read` 的工具，写了 `write` 工具的，检查报错。数据集合、知识、技能、专家、feed、规则都不开放。

2. **使用方在专家的 `uses` 里写全名。** `<模块>/tools/<名字>`：

   ```yaml
   uses: knowledge, tools/chain, stock-ta/tools/structure, stock-ta/tools/signals
   ```

   领队的 `domain_tool` 也列出它能调的外部工具，名字带模块前缀。

3. **在提供方那边运行。** 宿主找到提供方**当前在服务的版本**，用提供方的代码、数据目录、密钥（C2 以后是提供方自己的 `.env`）、时限运行这个工具，把结果交回调用方。调用方的任务钉住的是它自己模块的版本，外部工具不跟着钉。

4. **权限只看「只读」。** 外部工具都是只读的，按权威表（`AUTHORITY`）谁都能调，推断任务也能调。

5. **提供方不在时照常降级。** 提供方没装、关着、没开放这个工具，或这次调用失败，宿主回一行固定的原因，例如「stock-ta 没开，这部分没做」。使用方的任务照常运行，专家在汇报里写明哪部分没做。使用方的包检查对「`uses` 里写了外部工具」只给提醒，不报错，因为模块随时会装上、拿掉。

6. **有私密数据的模块不开放。** 模块里有 `private` 集合（例如 `mail` 的 `messages`）时，`exports` 检查报错。只读工具可能把私密内容带给别的模块的任务，这正是 ADR-0018 要挡的事。今天要开放的只有 stock-ta，它没有私密集合。（待定 2）

7. **访问记录。** 每次外部调用在提供方的访问记录里记一笔：调用方模块、任务、成员、工具、结果。宿主日志的 gateway 那一行带上调用方，例如 `stock-ta tools/structure tkt_… direction(option-ta) ok 5960 ms`。

## 兼容

- 开放的工具就是对外接口。提供方改它的输入输出，可能弄坏使用方的技能。
- `just module check --previous`（换版本时宿主也跑同一段检查）对比新旧版本：开放的工具被拿掉、或它的 `cases.json` 里有用例的输出形状变了，给提醒，写明「这个工具开放给了别的模块」。
- 宿主在模块页列出「谁在用我开放的工具」，从访问记录算出。

## 不做的

- 不开放数据集合。要别的模块的数据，经它开放的只读工具取。
- 不开放写工具。option-ta 要改 stock-ta 的自选股，由使用者在对话里对 stock-ta 说。
- 不做依赖声明（`requires`）和版本约束。只有一对提供方和使用方时用不上（YAGNI），第二对出现再说。
- 不经幕僚长。

## 分期

| 期 | 内容 | 验证 |
|---|---|---|
| C4a | `exports` 的检查（只读、无私密集合）；`uses` 认外部工具名；网关按提供方当前版本、数据、密钥运行外部工具；降级原因；访问记录带调用方 | 测试模块 A 开放一个只读工具，模块 B 的专家调用成功、数据来自 A；A 关掉时 B 拿到固定原因、任务不出错；A 开放写工具、或有私密集合时检查报错 |
| C4b | stock-ta 声明 `exports`；`--previous` 的兼容提醒；模块页的「谁在用」 | 一个只用 stock-ta 工具的临时模块，在临时宿主上由真模型调用 `stock-ta/tools/structure`，结果和 stock-ta 自己调用一致 |
| C4c | 模块工坊的技能 `package-layout`、`build-module` 写进 `exports` 和外部 `uses` | 工坊做 option-ta 时用到 |
