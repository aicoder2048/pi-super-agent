# 指标跟踪和预警

## 看趋势

用 `data` 读 lab-results 里这个项目的全部历史，按采样日期排。只比较同一家实验室的数值。还没有经使用者确认的数值（`confirmed` 是 false）照常算进趋势，但要指出是哪几个。先读知识库里的「肿瘤标志物跟踪要点」。

## 设提醒条件

提醒条件由宿主保存和检查，不靠你记。只有使用者亲口要求时才能改，用 `watch`：

- 越过某个数值：`above` 或 `below`
- 连续上升若干次：`rising-streak`
- 两次之间变化超过百分之几：`change-pct`

设完把宿主返回的清单念给使用者确认。条件满足时宿主直接提醒使用者，不经过你。数据点还没确认时，提醒里会写明「未经确认」。
