# 个人医疗健康

帮一个人整理自己的体检和检验报告、处方和设备数据，跟踪关键指标，在指标越线时提醒，并请一组专科顾问对同一份材料会诊。

这个模块包里没有任何人的病历。报告原件、提取出的指标、你设的提醒条件和你填的设置，都在宿主状态目录的 `modules-data/personal-health/` 下，不在这里。

## 这个模块用到什么

- 连接器：Google Drive（读你指定的一个文件夹）、邮箱（读你指定发件人的邮件）、webhook（收设备数据）、文献检索。
- 代码：一个算胰岛素敏感度的工具，一个把设备厂商格式转成读数的 feed 代码。两个都不联网，不要密钥。
- 数据：报告原件、检验指标、设备读数和基本信息是 `private`，文献检索到的研究进展是 `shareable`。级别不改变 Telegram 上的样子，汇报在网页和 Telegram 上都完整显示（ADR-0023）。
- 专家：五位顾问都只有 `read` 这一个 Pi 工具，能调用哪些能力写在各自文件开头的 `uses` 里。

## 提取出来的数值

Worker 从报告里读出的检验数值会记下它来自哪一份原件。数值可能读错，提醒里会写明出处，你可以对照原件。

## 边界

顾问团里的每一位都不是医生。结论必须写明依据。涉及用药调整和急症时，回答的第一句是请你联系医生或急救。
