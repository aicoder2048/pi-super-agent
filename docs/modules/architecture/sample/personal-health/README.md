# 个人医疗健康

帮一个人整理自己的体检和检验报告、处方和设备数据，跟踪关键指标，在指标越线时提醒，并请一组专科顾问对同一份材料会诊。

这个模块包里没有任何人的病历。报告原件、提取出的指标、你设的提醒条件和各个服务的授权，都在宿主状态目录的 `modules-data/personal-health/` 下，不在这里。

## 这个模块会用到什么

这一节不是权限声明。包里没有任何地方手写权限。宿主从各个组成里推导出下面这些，写在确认卡片上。

- 连接器：Google Drive（读你指定的一个文件夹）、邮箱（读你指定发件人的邮件）、webhook（收设备数据）、文献检索。
- 宿主能力：把「有新报告」告诉幕僚长。指标越线时直接提醒你。
- 网络：没有。模块自带的两个代码文件都不联网。
- 数据：报告原件、检验指标和设备读数是「私密」，基本信息是「仅本机」，文献检索到的研究进展是「可分享」。每一级能给哪些模型读，由你在 `config.json` 的 `dataRoutes` 里定，模块定不了。
- feed 的级别跟着它写进去的那类数据走。所以医院邮件和网盘报告的触发是「私密」，只有研究进展的触发能带上标题和链接。
- 专家：五位顾问都只有 `read` 这一个 Pi 工具，能调用哪些能力写在各自文件开头的 `uses` 里。

## 提取出来的数值要你确认

Worker 从报告里读出的检验数值先标成「未确认」。你在模块页上对照原件确认或改正。

## 边界

顾问团里的每一位都不是医生。结论必须写明依据。涉及用药调整和急症时，回答的第一句是请你联系医生或急救。
