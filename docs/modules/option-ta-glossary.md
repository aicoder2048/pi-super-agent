# option-ta 术语表（草稿）

拷问中定下的期权领域用语。模块包建好后搬进 `knowledge/glossary/`。这里只写含义，不写实现。

## 交易动作

一笔交易由一对开仓和平仓组成，中间可以有任意次 Roll。开仓可以是卖出，也可以是买入。

| 方向 | 开仓 | Roll（RTO） | 平仓 |
|---|---|---|---|
| 卖方（short） | STO | BTC + STO | BTC |
| 买方（long） | BTO | STC + BTO | STC |

PUT 和 CALL 都适用这张表。

**STO（Sell to Open）**：卖出开仓，收权利金。
**BTC（Buy to Close）**：买回平掉卖方仓位。
**BTO（Buy to Open）**：买入开仓，付权利金。
**STC（Sell to Close）**：卖出平掉买方仓位。

**Roll（RTO）**：
平掉现有期权、同时开一个新期权，当作一个动作。卖方的 Roll 是 BTC + STO，买方的 Roll 是 STC + BTO。分三种：
- **Calendar Roll**：行权价和张数不变，只换到更晚的到期日。
- **Diagonal Roll**：换行权价，到期日可换可不换，张数不变。
- **Combo Roll**：张数变了，不管行权价和到期日变没变。
_Avoid_：把 Roll 说成两笔独立的交易

**不由成交产生的结束**：
到期作废（Expire）；卖方被指派（Assignment，可能提前）；买方行权（Exercise）。它们也结束一笔交易，要和平仓一样记下来。

**被指派产生的股票**：
put 被指派时买进、call 被指派时交出的股票。第一版只记这一种股票进出（买方行权交割的股票记法相同），股票的其余买卖不记。所以第一版不知道账户里还有哪些股票批次，要股票批次的税务判断标「待确认」（`option-ta-tax-memo.md` 第 14.3 节）。

## 仓位

**CSP（Cash Secured Put）**：
卖出 put，并留足按行权价接股的现金。出发点分两种，见「意图」。

**CC（Covered Call）**：
持有正股的同时卖出 call。

**价差（Put/Call Spread）**：
同时卖出和买入同类、同到期、不同行权价的期权，风险有上限。开仓是一腿 STO 加一腿 BTO，平仓是 BTC 加 STC，Roll 同时动两腿。第一版只做垂直价差。

**意图**：
开一个仓位时的出发点。每一段仓位有自己的意图，不服从一个预设的循环。意图决定一个结局算「达成」还是「失手」；成败的大小一律用金额算。意图可以中途改，改的时间和原因记下来，成败按最后的意图判。从成交邮件记下的仓位没有意图时，问使用者一次；没回就按默认意图记，标「待确认」。
_Avoid_：Wheel、轮动（本模块不是 Wheel 策略，只是动作相似）

| 仓位 | 意图 | 达成 | 被指派或行权 | 到期作废 | 默认 |
|---|---|---|---|---|---|
| 卖 put（CSP） | 收租 | 赚到权利金 | 失手 | 达成 | 是 |
| 卖 put（CSP） | 折价接股 | 用低于下单时的价格接到股票 | 达成 | 安慰（权利金照收） | |
| 卖 call（CC） | 收租 | 赚到权利金，股票留着 | 失手 | 达成 | 是 |
| 卖 call（CC） | 溢价出货 | 在行权价加权利金的价位卖出股票 | 达成 | 安慰（权利金照收） | |
| 买 put | 买保险 | 下跌时保护住手里的股票 | 不适用 | 正常（保险费） | 是 |
| 买 put | 看跌 | 方向对了，赚钱 | 不适用 | 失手 | |
| 买 call | 看涨 | 方向对了，赚钱 | 不适用 | 失手 | 是 |
| 买 call | 替代持股 | 用较少的钱拿到接近持股的涨幅 | 不适用 | 失手 | |
| 贷方价差 | 限定风险收租 | 赚到净权利金 | 失手 | 达成 | 是 |
| 借方价差 | 限定成本看方向 | 方向对了，赚钱 | 不适用 | 失手 | 是 |

不做裸卖 call。

## 名单

**期权自选**：
option-ta 自己的一份标的名单，初始为空。标的加进来时回填最近一年的 IV，之后每天收盘后存一份，供 IV rank 和百分位用。只由领队写入。它和 stock-ta 的自选股是两份名单，加进一份不会加进另一份。
_Avoid_：自选股（那是 stock-ta 的名单）、关注的标的

## 成交来源

**成交回信**：
券商交易台对使用者下单邮件的人工回信，贴一张「非正式更新」表，列出哪些成交了、哪些还挂着，声明以对账单为准。`fills` 从它记成交。
_Avoid_：成交确认单（那是券商系统发的正式文件，这批信不是）

**挂单**：
已经下了、还没成交的单。表里有挂单数量、没有成交数量。不是成交，不记。

## 行情

**预计除息日**：
还没宣布的下一次除息，按最近一次常规现金股息的除息日和发放频率推出来的日子。只用来发静音提醒，提醒里标「预计、未宣布」；正式宣布后换成宣布的除息日。推法见 `option-ta-spec.md`「主动提醒的两处细节」。
_Avoid_：把预计除息日说成除息日

**自算**：
供应方没给 IV 或希腊值时，模块用报价中间价按 BS 自己算出的值，标「自算」。算不出时标「无数据」，不当 0。

## 评判

**赢的金额**：
评判成败主要看赢了多少钱，而不是赢的次数占比。胜率只作参考。
_Avoid_：用胜率作为首要指标
