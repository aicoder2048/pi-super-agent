# 世界时间 `/now`

```sh
just now
# 或：pi --no-skills --no-extensions -e extensions/now.ts
```

进入 Pi 后输入 `/now`。

## 展示方式

- 标题使用当前主题强调色，时间加粗，日期与 UTC 偏移使用次级文字色。
- 宽屏采用对齐时间表；超宽屏增加 IANA 时区列；窄屏自动切换为分行布局。
- 本地时间优先展示，轻分隔线区分全球城市；不使用固定 RGB 或切换全局主题。
- 使用 Pi 的“展开工具输出”快捷键（默认 `Ctrl+O`）查看完整 IANA 时区及地区定位说明。消息底部会显示实际配置的快捷键。
- 结果是一次性快照，不是实时钟表。窗口缩放、主题切换或展开不会更新时间。

TUI 结果会保存在当前会话中，不触发模型回复。RPC 保留纯文本通知；无 UI 时输出到 `stderr`，不污染 `stdout` 事件流。

本地时间取 Pi 进程所在环境时区。所有城市采用同一时间点，夏令时由 IANA 时区自动计算；输出不表示交易日或市场开市状态。

## 验证

```sh
just test-now
```

需要 Node.js 22.18+ 或 24+。测试优先解析本地 Pi 依赖；没有本地安装时通过 `npm root -g` 复用全局 `@earendil-works/pi-coding-agent` 的依赖。

覆盖日期跨日、夏令时、TUI/RPC/无 UI 分支、展开详情、深浅主题、中文列对齐与不同终端宽度。
