# W2 界面用语规范

原则：
1. 主语统一。产品称「Pi Super Agent」，和你对话的称「幕僚长」，执行者称「助手」，使用者称「你」。不用「它」「我」。
2. 一个概念一个词：任务（ticket）、助手（worker）、消息（外部触发）、来源（source）、规则（rule）、执行过程（transcript）。不混用「事 / 活 / 任务」。
3. 简洁中性的产品语气。不用口语和拟人化的说法（「看了看」「长活」「刚上岗」「拿主意」「交给它一件吧」）。
4. 标题用名词短语，状态用两到三字的固定词，提示用完整短句并带句号。
5. 技术细节只在右栏底部小字出现，用正式写法（tokens、编号）。

## 命名

| 对象 | 页面上的叫法 | 说明 |
|---|---|---|
| 产品 | Pi Super Agent | 页头和浏览器标签页标题。 |
| 和你对话的（Router） | 幕僚长 | 对话区开场、对话里幕僚长消息上方的名字标签、执行过程的步骤。 |
| 执行任务的（Worker） | 助手 | 每位助手有一个名字（取自固定名字池，不用人名）、一个角色和当天的序号，写作「边牧 · 行情助手 #2」。工具图标的颜色按任务编号固定取色。 |

只改网页。TUI 和 Router 的提示词不在范围内。

## F1 新增（选项回答与久无进展）

| 位置 | 用语 | 说明 |
|---|---|---|
| 点选项发出的话 | 回答任务「标题」：选项 | 由宿主写好，作为你的一句话出现在对话里，和「停止任务「标题」」同一句式。 |
| 选项按钮下方 | 发送中… | 这个页面的点选还没收到宿主回应，按钮锁住，选中的一项高亮。 |
| 选项按钮下方 | 已发送，等待幕僚长转交 | 宿主收下了点选，幕僚长还没把它转交给任务。任何客户端都一样显示。 |
| 选项按钮下方 | 已回答 | 点选已经转交给提问的任务，按钮锁住，选中的一项高亮，直到任务下一次汇报。 |
| 选项按钮下方 | 幕僚长没有转交这次选择，请重选或直接回复 | 幕僚长忽略了点选或没有转交，按钮重新可点。 |
| 选项按钮下方 | 你刚发了一句话，等幕僚长处理完再点 | 提问之后打的字幕僚长还没处理完，按钮锁住。 |
| 待你处理卡片的阶段 | 久无进展 · N 分钟 | 执行中的任务超过 Watchdog 的 stuckMinutes 没有进展时显示，分钟数随时间增加，卡片保留「停止」按钮。 |
| 发送状态 | 发送失败：这个问题已经回答过，或已不在等待回答。 | 点选项时宿主回 409，问题已被打字回答或被新问题取代。 |
| 发送状态 | 发送失败：已选「X」。 | 换另一项再点，宿主回 409；X 用页面自己的选项文字。 |

## W5 新增（助手条与生命周期）

| 位置 | 用语 | 说明 |
|---|---|---|
| 助手全名 | 名字 · 角色 #N | 例如「边牧 · 行情助手 #2」。出现在任务卡片标题下、执行过程头部和 TUI 卡片。名字在建任务时取定，同一时刻在岗的助手不重名；名字池用完时加「·二」。 |
| 角色 | 对话助手 | 你的请求开的任务。 |
| 角色 | 行情助手 | 行情来源（模块清单里标了 market 的来源，如 toy-market、us-market）按规则开的任务。 |
| 角色 | 规则助手 | 其他来源按规则开的任务。 |
| 角色 | 观察助手 | 幕僚长主动发现开的任务。 |
| 序号 | #N | 按角色、按纽约日期从 1 数。 |
| 助手条（页头下方） | 在岗助手 | 读屏标签。每位在岗助手一枚小卡，没结束的任务都算在岗。 |
| 小卡状态 | ● 运行中 / ◐ 空闲 / ○ 排队 | 小卡上只有这个圆点，不再放任务图标。圆点后写名字、角色序号、用时和 tokens，例如「边牧 对话助手 #1 3分5秒 · 1.5k tokens」。点小卡在右栏打开该任务的执行过程。 |
| 助手条末尾 | 今日 N 位 · X tokens | 纽约日期今天开的任务数和它们的 token 合计。没有在岗助手时助手条只留这一句。 |
| 执行过程头部 | 生命周期行 | 「开始 HH:MM · 结束 HH:MM · 用时 X · 模型 X · 工具 N 次 · tokens 入 A / 出 B」；没结束时「结束 HH:MM」换成「进行中」；回退模型写「模型 X（已回退）」；还没开始时写「尚未开始 · 模型 未启动 · …」。时间按浏览器所在时区。 |
| 右栏小字 | 编号 abcd | 模型、用量、工具次数和用时移到生命周期行，小字只留编号。 |

## W5 新增（对话里每句话的去向）

你的每句话下面一行小字，写幕僚长怎么处理了它。取自这条话记下的去向，看板每次推送都会更新，不用刷新。

| 去向 | 用语 | 说明 |
|---|---|---|
| 开了新任务 | 已开新任务「标题」 · 名字 · 角色 #N | 点这一行在右栏打开该任务的执行过程。 |
| 交给已有任务 | 已交给 名字 · 角色 #N（标题） | 点这一行在右栏打开该任务的执行过程。 |
| 幕僚长回复了、没开任务 | 幕僚长直接回答 | 不可点。 |
| 幕僚长还没处理完 | 幕僚长处理中 | 不可点。 |
| 幕僚长判断不用处理 | 幕僚长判断无需处理 | 不可点。和「今日来源消息」里的「无需处理」同一个词；幕僚长写的理由不显示。 |
| 幕僚长看过、既没决定也没回复 | （不写） | |
| 看板上找不到那个任务 | 已开新任务 / 已交给助手 | 只在任务已被看板列表挤出时出现。 |
