# W2 界面用语规范

原则：
1. 主语统一。产品称「白宫」（副标题 Pi Super Agent），和你对话的称「幕僚长」，执行者称「助手」，使用者称「你」。不用「它」「我」。
2. 一个概念一个词：任务（ticket）、助手（worker）、消息（外部触发）、来源（source）、规则（rule）、执行过程（transcript）。不混用「事 / 活 / 任务」。
3. 简洁中性的产品语气。不用口语和拟人化的说法（「看了看」「长活」「刚上岗」「拿主意」「交给它一件吧」）。
4. 标题用名词短语，状态用两到三字的固定词，提示用完整短句并带句号。
5. 技术细节只在右栏底部小字出现，用正式写法（tokens、编号）。

## 命名

| 对象 | 页面上的叫法 | 说明 |
|---|---|---|
| 产品 | 白宫 | 页头名字；浏览器标签页标题写「白宫 · Pi Super Agent」。见下文「产品名」一节。 |
| 和你对话的（Router） | 幕僚长 | 对话区开场、对话里幕僚长消息上方的名字标签、执行过程的步骤。 |
| 执行任务的（Worker） | 助手 | 每位助手有一个名字（取自固定名字池，不用人名）、一个角色和当天的序号，写作「青檀 · 行情助手 #2」。任务的领域（模块）有成员时，助手是这个队的领队，用四字名，角色的位置写「队名领队」：「高山流水 · 美股看盘队领队 #2」。头像的颜色按任务编号固定取色（见「头像」）。 |

只改网页。TUI 和 Router 的提示词不在范围内。例外是「引用」：它也改了 TUI、just tail 和幕僚长、助手的提示词，见下文「引用」一节。

## 产品名

产品叫「白宫」。「Pi Super Agent」是副标题，不再单独作产品名出现在界面上。使用者是「你」（principal，白宫为你服务）；幕僚长和助手的叫法不变。

| 位置 | 用语 | 说明 |
|---|---|---|
| 浏览器标签页标题 | 白宫 · Pi Super Agent | 历史记录和书签里仍能搜到 Pi Super Agent。 |
| 页头名字 | 白宫 | 字重 800，字距约 0.06em。 |
| 页头副标题 | Pi Super Agent · 你的 24 小时幕僚 | 原「你的 24 小时助理」。 |
| 页头标志和标签页图标 | W1：深蓝圆角方块、白色椭圆环、中间琥珀色圆点 | 原创图形。小尺寸加粗笔画：32px 档笔画 5.5、圆点 5；20px 档笔画 7、圆点 6。 |
| 你的头像 | U2：深蓝圆底、琥珀色椭圆环、环内琥珀色五角星 | 在你每条消息的右侧，和幕僚长消息左侧的 π 头像对称。读屏不念头像，仍念「你：」前缀。 |
| 演示字幕 | 白宫：… | 和「普通聊天机器人：…」对照的那一行。 |

只用「白宫」这个名字，不用任何官方标识：没有总统印章、白头鹰、建筑剪影。代码标识符、命令、包名、状态目录 `~/.pi-super-agent` 和 `just` 配方都不改名。

## T2 新增（派活）

任务的领域（模块）有成员时，助手可以把事派给成员。成员在页面上只写职称，不起名字，也不写它的英文 `name`。

| 位置 | 用语 | 说明 |
|---|---|---|
| 助手小卡下面 | 职称 · 正在做的步骤 · 多久前 / 职称 · 正在做的步骤 · 已多久 / 职称 · 排队中 | 正在干活的成员每位一枚小标签，例如「新闻研究员 · 读取网页 · 12 秒前」：步骤名和执行过程里的一样，成员刚启动还没有步骤时写「启动中」；时间是离它上一次动静多久，5 秒内写「刚刚」，之后写「N 秒前」「N 分钟前」。成员有工具调用还没返回时改写这一步已经跑了多久，例如「技术分析师 · 执行命令 · 已 2 分钟」，一分钟内写「已 N 秒」，不到一秒写「刚刚」；同时有几个没返回，写最早开始的那个。还没轮到的写「新闻研究员 · 排队中 · 上限 4」，虚线边框，「上限」后面是现在全宿主同时运行的成员上限。做完就消失。成员多了自动换行。助手自己的名字和角色不变。读屏标签在小卡末尾加「，成员：」和这些标签。 |
| 步骤（工具） | 派活 | 每次派活一条分支，同一轮并行的派活画成几条分支，同在一个「派活」步骤下（见「执行过程的图标和派活分支」）。分支上写「职称 · 状态」，例如「行情分析师 · 进行中」；助手一发出派活就写得出职称。一批里先做完的那位马上写「完成」。 |
| 派活的状态 | 排队中 / 进行中 / 完成 / 超时 / 无进展 / 已停止 / 出错 | 排队中：等同一位成员手上的事做完，或等全宿主的名额（`maxConcurrentExperts`，默认 4，使用者可以按天放宽到 10，见「T2b 新增」）。超时：从成员开始干活算起超过时限，能写文件、改文件或执行命令的成员是 `dispatchCodingTimeoutSeconds`（默认 60 分钟），其余是 `dispatchTimeoutSeconds`（默认 15 分钟）；或排队超过 `dispatchTimeoutSeconds`。无进展：成员没有工具调用在跑，又连续 `dispatchStallSeconds`（默认 3 分钟）没有任何动静，被宿主结束；工具调用还没返回时不计，一直不返回的算超时。已停止：任务被叫停、宿主停止或重启、助手退出。出错：成员的模型报错，成员的进程号记不下来，或排队轮到时回退模型今日用量已达上限（这时不起成员进程）。超时、无进展和出错的步骤记号是「!」，已停止是「■」。 |
| 没等到结果的步骤 | （记号「■」） | 任务被叫停、助手退出或宿主重启时还没有结果的步骤不再显示等待中的「…」，改成「■」；其中的派活写「职称 · 已停止」。 |
| 步骤展开 | 派活明细 | 第一行「职称 · 状态 · N tokens」（token 是输入加输出，成员干活时跟着涨；没等到结果就停下的派活，例如任务被叫停或宿主被强杀，数字从成员自己的会话里每次模型调用的用量加出来，成员一次调用都没做完时不写）；第二行「任务：」加助手派给它的原话；有原因时再一行，例如「超过 15 分钟的时限」「3 分钟没有进展」「排队 15 分钟还没轮到」或模型的报错；然后是成员自己的步骤，每步一行「记号 步骤名 细节」，干活时一条条加上，做完后还在；最后是成员的回复。 |
| 成员的回复、幕僚长的话、任务卡上的结论、汇报那一步 | （按 Markdown 显示） | 只认标题、段落、列表、表格、粗体、斜体、行内代码；链接写成「文字（网址）」，不可点；HTML 标签原样当文字。成员超过 2000 字的回复在交给助手前已截断，末尾写「…（回复超过 2000 字，已截断）」。汇报那一步用整段话渲染，不按字数截；高过 240px 时在框里滚动，和成员回复一样。 |

## T2b 新增（成员上限）

成员因为名额用完而排队时，宿主问你要不要把当天的上限放宽到 10（ADR-0010）。问题由宿主提，不经过幕僚长。

| 位置 | 用语 | 说明 |
|---|---|---|
| 待你处理的卡片标题 | 成员上限 | 排在待你处理的最前面，算进标题的数字。不属于任何任务：没有助手名，点卡片不打开执行过程，没有「停止」。 |
| 卡片标题下面一行 | 白宫 · 系统 | 写在任务卡片写助手名字的位置，加粗；卡片左边一条 4px 的强调色竖线。只有宿主自己的这张卡片有这一行和这条线。助手可以提一个标题、问题、选项都一样的问题，那仍是一张任务卡片：这一行写的是助手的名字（例如「青檀 · 对话助手 #1」），左边没有竖线，点它回答的是那个任务，上限不变。 |
| 卡片的阶段 | 待回复 | 和任务卡片的「待回复」同一个词。 |
| 卡片的问题 | 现在有 N 位成员在排队，同时运行的成员上限是 4。今天放宽到 10 吗？ | N 是这一帧里在等名额的派活数，排在自己那位成员后面的不算。4 是配置的上限。 |
| 卡片的问题（没人排队时） | 今天有成员排过队，同时运行的成员上限是 4。今天放宽到 10 吗？ | 排队的都轮到了，问题还开着。问题留到纽约当天结束。 |
| 选项 | 今天放宽到 10 / 保持 4 | 「保持」后面是配置的上限。点「今天放宽到 10」后上限马上是 10，排队的成员立刻开始，到纽约当天结束为止；点「保持 4」后这一天不再问。 |
| 点选项发出的话 | 回答成员上限：今天放宽到 10 | 由宿主写好，作为你的一句话出现在对话里。它下面没有去向那一行，因为它不交给幕僚长。 |
| 选项按钮下方 | 发送中… / 已发送 | 宿主收下后卡片随下一帧看板收起，没有「等待幕僚长转交」这一段。 |
| 排队成员的小标签 | 职称 · 排队中 · 上限 N | N 是现在的上限：配置值，或放宽后的 10。 |
| 发送状态 | 发送失败：已选「X」。 / 发送失败：这个问题已经回答过，或已不在等待回答。 | 答过之后换另一项再点；或点的是前一天留在页面上的按钮。 |
| TUI 看板 | cap 成员上限 … 等你回答 · 白宫 · 系统 | 下面两行是问题和编号选项。只有它在等时回复数字作答，否则用 `/answer cap <序号>`。行尾的「白宫 · 系统」只有宿主的问题有：任务那一行的行尾是「等你回答 · 请求 / 规则 / 推断」，编号是四位字符，不会是 cap。 |

## W5 新增（对话里每句话的去向）

你的每句话下面一行小字，写幕僚长怎么处理了它。取自这条话记下的去向，看板每次推送都会更新，不用刷新。

| 去向 | 用语 | 说明 |
|---|---|---|
| 开了新任务 | 已开新任务「标题」 · 名字 · 角色 #N | 点这一行在右栏打开该任务的执行过程。 |
| 交给已有任务 | 已交给 名字 · 角色 #N（标题） | 点这一行在右栏打开该任务的执行过程。 |
| 幕僚长回复了、没开任务 | 幕僚长直接回答 | 不可点。 |
| 幕僚长还没处理完 | 幕僚长处理中 | 不可点。 |
| 幕僚长判断不用处理 | 幕僚长判断无需处理 | 不可点。和「今日来源消息」里的「无需处理」同一个词；幕僚长写的理由不显示。 |
| 幕僚长看过、既没决定也没回复 | （不写） | |
| 看板上找不到那个任务 | 已开新任务 / 已交给助手 | 只在任务已被看板列表挤出时出现。 |

## 清屏

清屏只把对话栏里的行藏起来，不删任何记录，也不对幕僚长说话：数据库里的行和幕僚长的记忆都不变，清屏之后它仍能接上「刚才那件事」。标记存在宿主上，所有打开着的网页同时清空，重载、换浏览器、重启宿主后都还是清屏后的样子。没有撤销。TUI 没有清屏命令，已经打印的行也收不回来。

| 位置 | 用语 | 说明 |
|---|---|---|
| 输入框下方、状态文字右端的下划线文字 | 清屏 | 看起来是可点的文字，不是按钮。和「发送」分开，不弹确认框：点错了用对话栏顶部的细线就能看回去。对话为空时不可点，也不带下划线。 |
| 对话栏顶部的细线 | 已清屏 · HH:MM · 显示之前的 | 点它只在这个标签页展开被清掉的最近 50 行，展开的行颜色淡一些，下面没有选项按钮。不是今天清的屏写成「已清屏 · M月D日 HH:MM · 显示之前的」。 |
| 展开之后的细线 | 已清屏 · HH:MM · 收起 | 再点收起。下一次清屏或重载页面时也收起。 |
| 发送状态 | 清屏没有成功，请稍后再试。 | 宿主没收下这次清屏。 |

## 引用

引用一句对话只是给幕僚长和助手的上下文，不是你的新要求：页面只发出被引用那一行的编号，宿主记下那一行当时的一行快照（最多 200 字），之后谁都读同一份。对话栏里能看到的每一行都能引用，你的、幕僚长的，清屏后展开的旧行也行。引用跟着你那句话存在宿主上，重载、换浏览器、重启宿主后都还在。

| 位置 | 用语 | 说明 |
|---|---|---|
| 每行气泡下方的小字 | 引用 | 鼠标移到这一行上或键盘移到这一行时出现；触屏上点一下气泡出现，点气泡外的选项和任务行不会。 |
| 输入框上方的灰色引用条 | 引用 幕僚长：… / 引用 你：… | 幕僚长的话去掉 markdown 标记，你的话照原样；都压成一行，最多显示两行。 |
| 引用条右端 | ✕（读屏念「取消引用」） | 在输入框里按 Esc 也能取消；正在用输入法打字时 Esc 只交给输入法。 |
| 你的气泡下方的灰色小框 | 幕僚长：… / 你：… | 发出之后显示，最多两行。读屏念「引用 幕僚长：…」。 |
| TUI 和 just tail | ↪ 引用 幕僚长：… / ↪ 引用 你：… | 打在引用了它的那句「你> …」前面一行；just tail 前面带时间。just say 不能引用，输出不变。 |

## 头像

头像只是装饰，旁边的名字和职称照写，所以读屏跳过它（`aria-hidden`）。同一个任务的头像在任务卡片标题前、助手条小卡和执行过程头部是同一个字、同一种颜色，颜色由任务编号决定，重载后不变。

| 位置 | 用语 | 说明 |
|---|---|---|
| 助手头像 | 名字的第一个字 | 例如「青檀」写「青」。单个助手是圆形；团队任务的领队是方形，上面一个冠标，模块被拿掉后仍是领队的样子。旧任务还没有助手时画一把扳手。 |
| 成员头像 | 职称的第一个汉字 | 例如「行情分析师」写「行」，「Pi 扩展专家」写「扩」（跳过开头的「Pi 」）。同一张卡片上两位成员首字相同时都写两个字，例如「技术」「技能」。颜色由职称决定，同一职称在哪张卡片上都是同一种颜色。 |
| 团队任务的卡片底部 | 成员头像 + 领队派活那一句 | 例如叠着「行」「新」两个头像，后面写「派给 行情分析师、新闻研究员」。没派过活时只有那一句，例如「领队独自完成」。单个助手的任务和没有派活记录的旧任务没有卡片底部。 |

## 执行过程的图标和派活分支

图标和头像一样只是装饰，读屏跳过（`aria-hidden`）。步骤名称、状态和派活的说法都不变。

| 位置 | 用语 | 说明 |
|---|---|---|
| 步骤左边的图标 | 每种步骤一个线条图标 | 读文件是文件，改写文件是笔，搜索和查找是放大镜，列目录是文件夹，命令和后台命令是终端，读网页是地球，查数据是折线，查阅任务记录是单据，交回幕僚长是返回箭头，汇报是对话框，派活是分叉箭头，思考是灯泡，收到的输入是收件箱，未知工具是扳手。图标放在步骤的圆形记号里，原来的记号「✓」「!」「…」「■」挪到右下角的小圆标里，读屏照旧念它。 |
| 派活分支 | 成员头像 + 「职称 · 状态」 | 助手同一条消息里发出的几次派活是同一轮，画在同一个「派活」步骤下，放在这一轮第一次派活的位置；只派一位时也画成一条分支。头像和卡片底部的一样。电脑上执行过程栏较窄，分支上下排列；栏宽放得下两条时（如平板宽度）才左右并排。展开某条分支的「派活明细」时，它占满一整行。 |
| 分支的时间行 | 已用 38 秒 · 时限 15 分钟 / 用时 38 秒 · 时限 15 分钟 | 进行中写「已用」，每秒往后数；结束后写「用时」。不到一分钟写秒，否则写整分钟。时限按成员在这个任务里的时限写，整分钟写分钟，否则写秒，和「超过 15 分钟的时限」的说法一致。排队中、没开始就结束（排队超时、被拒）、没等到结果就停下的分支不写时间行。这个说法出现之前的会话记录里没有时限，刷新后只写「用时 38 秒」。 |
| 分支的进度条 | （悬停和读屏）按时限折算，不是完成度 | 只在进行中显示，长度是已用时间除以时限，到时限时满格。成员不报告完成度，所以写明这一句。 |

## Telegram

Telegram 机器人是网页和终端之外的第三个客户端，规则见 ADR-0016，部署见 `docs/deploy/telegram.md`。机器人只发纯文本，不用 Markdown；一条消息最多 4000 个字符，超出的截断，不拆成几条。称呼和网页相同：白宫、幕僚长、你。

| 位置 | 用语 | 说明 |
|---|---|---|
| 幕僚长的回复 | 原文 | 带通知。 |
| 你在网页或终端说的话 | 你在网页或终端说：… | 静默，手机不响。 |
| 你在名单上另一个 Telegram 账号说的话 | 你在另一个 Telegram 账号说：… | 静默。名单上有不止一个 id 时才会出现。 |
| 超长消息的结尾 | …（全文见网页） | 只有很长的网页消息转过来时才会用到。 |
| 回 `/start`、`/help` | 这里是白宫。你在这里打的字就是对幕僚长说的话，和网页、终端是同一个对话；幕僚长的回复也发到这里。助手提问时会发来带按钮的问题，点按钮就是回答；成员上限只能在网页或终端回答。只收文字，转发的消息不会交给幕僚长。 | 引用加上之后这一段跟着改。 |
| 回图片、语音等非文字消息 | 目前只收文字消息，这条没有交给幕僚长。 | |
| 回转发的消息 | 转发的消息不会交给幕僚长。要问幕僚长，复制文字后用你自己的话发。 | 转发的是别人的话（ADR-0011 同理）。 |
| 回经别的机器人发出的消息 | 经别的机器人发出的消息不会交给幕僚长。要问幕僚长，直接在这里打字。 | 用 `@某机器人` 发出的内容是那个机器人写的，和转发同理。 |
| 一条消息说不准到没到 | 有一条消息可能没送到手机上，网页上有完整对话。 | Telegram 出错或连接中途断了时，那条不重发；之后发到这个聊天的文字消息第一行是这一句，直到一条带着它的消息确定发到；问题卡片不带。没有别的消息时单独发这一句，每次故障最多单独发一次。 |
| 设置模式回来信的人 | 你的 Telegram 数字 id 是 987654321。把这个数字写进宿主状态目录里 config.json 的 telegram.allowedUserIds，重启宿主后就能在这里和幕僚长对话。 | 只在名单为空时出现，每个聊天一次。 |
| 问题卡片的开头 | 青檀 · 对话助手 #1 问你（任务「查天气」）：（换行）查哪个城市？ | 每个聊天里每个问题只发一张，带通知。没有助手名的旧任务写「助手问你」；任务标题超过 40 个字截断。 |
| 问题卡片的按钮 | 选项原文，一行一个 | 只在还能点时出现：没点过，或幕僚长没有转交上次的点选。 |
| 问题卡片最后一行 | 直接打字回答。 | 没有选项的问题，没有按钮。 |
| 问题卡片最后一行 | 已选「X」，已发送，等待幕僚长转交 | 在 Telegram、网页或终端点过之后，和网页卡片同一句；按钮消失。 |
| 问题卡片最后一行 | 已选「X」，已回答 | 点选已经转交给提问的任务。 |
| 问题卡片最后一行 | 幕僚长没有转交这次选择，请重选或直接回复 | 按钮重新出现。 |
| 问题卡片最后一行 | 已插话：你刚发了一句话，等幕僚长处理完再点 | 提问之后打的字幕僚长还没处理完，按钮消失；处理完后按网页的规则恢复。没有选项的问题写「已插话：你刚发了一句话，等幕僚长处理」。 |
| 问题卡片最后一行 | 已结束：你选了「X」 / 已结束：这个问题已经回答过，或已不在等待回答 | 问题离开看板时编辑成这一句，按钮消失。还没发出就结束的问题不发。 |
| 点按钮后的提示 | 已发送 | 宿主收下了点选。同一个按钮再点也是这一句，不会再答一次。 |
| 点按钮后的提示 | 已选「X」 / 这个问题已经回答过，或已不在等待回答 / 你刚发了一句话，幕僚长处理完之前不能点选项 | 宿主拒绝时的原因，和网页的「发送失败：…」同一组句子。 |
| 成员上限 | 成员上限：现在有成员在排队，宿主在问要不要今天放宽上限。这个问题只能在网页或终端的「待你处理」里回答。 | 每个问题只发一次，没有按钮，之后不再编辑（ADR-0010、ADR-0016）。 |
| 点伪造的成员上限按钮后的提示 | 成员上限只能在网页或终端的「待你处理」里回答 | 宿主也会拒绝（`not_here`），不靠客户端自觉。 |
